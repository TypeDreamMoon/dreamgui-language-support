# DreamUI Language Support

[English](README.md) | 简体中文

DreamGUI `.dui` 界面层级的语言支持。

## 功能

- **全语法高亮 + 语义身份着色**:绑定表达式(`Enabled <- !IsBusy() && Count() > 0`)、双向箭头
  (`Value <-> Volume`)、`use "…"` 导入与循环来源的两种形状都在语法高亮里;语义层按身份着色——
  节点 id 按"它将成为的成员变量"、样式按类、资源按只读常量、`->` 事件与处理函数、调用按函数、
  裸名字按变量、`each` 体内的 `Item.Member` 首段按它引用的循环参数、组件各归其位。
- **按上下文补全**:内建 tag、组件类、逐类属性、枚举值、槽属性、资源类型、`@` 资源引用、`->` 事件名;
  数据来自插件导出的 `.dui-symbols.json` —— 补全提供的恰是编译器接受的,单一清单不漂移。
- **颜色芯片与取色器**:每个 `#hex` 字面量都有色块;取色器保持你的位数风格(`#F00` 保持短形式),
  且永不改写 `@` 引用。
- **hover 带 UPROPERTY 说明与类默认值**(默认值按语言自己的拼法打印,可直接粘贴);大纲含具名槽与循环;
  token 级折叠与逐级扩选。
- **诊断用编译器的码与原文**:词法码 DUI1001–1006、单文件可判的结构码(含 DUI2013 嵌套上限),
  severity 与编译器一致;编译器仍是权威 —— 它可能接受的,这里至多是警告。每条码可点开中文解释。
- **workspace 导航**:Ctrl+T 搜全部 id/样式/资源;F12 按在嵌套 `/Game/X` tag 上落到声明它的文件,
  按在 `use "…"` 的拼写上打开被导入的文件(工作区里恰好一个文件匹配时才跳,宁可不跳不跳错);
  样式/资源/类路径的 find references。
- **会说这门语言的改名(F2)**:改节点 id 会**自动写 `(was: 旧Id)`**,下次编译迁移图引用、绑定与动画;
  改回旧名则删除子句。本地化 key 变化会提醒,并给出 `@key` 钉住旧 key 的写法。
- **提取与内联**:字面量提取为 `@资源`(单处或全部同值);选中属性行提取为样式;穿着的样式按
  基先派后展开回节点。
- **编译器诊断实时送达**:Unreal 编辑器开着时,每次编译 text-backed 类都会把裁决写进
  `DUI/.dui-diagnostics.json`,以 `dui-compiler` 来源出现在问题面板 —— 语义层(未知属性、坏值、
  缺失的绑定函数)与语法层并排,而扩展自己不长第二个编译器。
- **桥接 Unreal 编辑器**:`<-` / `->` 补全向活编辑器询问该类真正声明的函数;打 `/` 补全全部可嵌套的
  widget 类(编辑器在线走资产注册表,离线走 workspace 的 class 行);
  **Reveal in Unreal Designer** 打开设计器并选中光标所在节点;**Compile This File** 立即编译,
  裁决落在问题面板。
- **绑定表达式里的语义**:调用处有签名帮助(`(` 与 `,` 触发),函数与变量的 hover 给类型,
  `<->` 右侧补全列出该类的变量(带 FieldNotify 的排前,其余是每帧轮询),`each` 体内 `Item.`
  按数据源的元素类型补全成员。
- **格式化文档**(并作为 `[dui]` 的默认格式化器):按块深度缩进、`=` 与箭头两侧单空格、`}` 独占
  一行、空行折叠到一行 —— 与设计器写回的打印器同一套拼法,两个工具不会互相打架;结果重新分词,
  任何会改动 token 的格式化都被拒绝。
- **补 `use`**:样式或资源只在工作区另一个文件里声明时,quickfix 直接插入导入语句,拼法跟随文件
  里已有的 `use`。
- **包路径可点**:tag 或字符串里的 `/Game/...` 在活编辑器的内容浏览器里定位并打开(指向另一个
  .dui 的 tag 仍走 F12 跳到那个文件)。
- **从 Unreal 设计器 Reveal 到 VS Code**:工具栏与层级右键菜单一键跳到节点所在行;单独打开一个
  `.dui` 也会连同它所在的 `DUI/` 树一起索引,不开文件夹导入也能解析。
- **新文件命令**:与 Unreal 编辑器"Create Source File..."逐字节同款的 starter ——
  一个 root 加一个居中标签,用"出现了"回答"这一步成功了吗"。

## 智能从哪来

语义真相只有一份,在 C++ 编译器里。扩展的分工:

- **单文件字符能判定的**(词法、结构)—— 本地实时判,措辞照编译器逐字;
- **需要反射与类知识的**(属性、值、绑定)—— 由编译器经诊断信箱送达,或经桥实时询问;
- 两者都拿不到时,**明说降级**(状态栏),绝不猜。

## 构建

```
npm install
npm test            # tsc + node --test,不需要 VSCode 也不需要引擎
npm run build       # 打包到 out/extension.js
npm run package     # 产出 .vsix
```

设 `DREAMUI_CORPUS_DIR` 指向工程的 `DUI/` 目录,`npm test` 会把每个真实文件扫一遍,
词法与结构层必须零报。
